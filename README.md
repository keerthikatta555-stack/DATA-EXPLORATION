This project uses Excel to analyze a product dataset and extract useful information from the data.

## What I Did
- Created Price Range using the IF function
- Calculated Electronics total price using SUMIF
- Counted products below $100 using COUNTIF
- Extracted Day using LEFT
- Extracted Country Code using RIGHT
- Extracted Month using MID
